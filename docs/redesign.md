# 2026年9月 デザイン改修

参照は `Shinobi Lock.html` の「2: 1a 静かな台帳 全画面展開」。初期比較案の1b・1cは採用しない。

## 画面と操作

- ホームは実際のロック件数と切り替え時刻を表示する。複数ルールが重なる場合、すべて解除される時刻だと誤解させないよう「次の切り替え」と表示する。
- 各カードをタップするとルールを編集する。右上のスイッチは有効・休止だけを変更する。
- 作成・編集はラベルと入力欄を縦に並べる。曜日の「平日・毎日・週末」で選択を置き換える。
- ルール名の文字数を表示する。名前・曜日・時間の不備は保存時に該当欄へ表示し、その欄へスクロールする。
- 対象アプリは常に一覧で表示する。「選び直す」はiOS標準のFamilyActivityPickerを開く。
- 広告説明は対象アプリと2つの条件を示し、操作ボタンを画面下部に置く。失敗は赤いメッセージと「もう一度試す」、途中終了は通常色のメッセージで表示する。
- 解除完了は残り時間と進捗バーを表示する。「忍びロックのホームへ」は本体のホームへ戻る。
- 削除確認にはルール名、一括休止確認には現在のロック件数とルールが残ることを表示する。
- ShieldはOSが許可する背景・文字・アイコン・ボタンの色だけ変更する。

## 表示

背景 `#161826`、カード `#232532`、本文 `#e9e9ed`、アクセント `#9184d9`。カードは角丸14pt、入力とボタンは8pt。主要ボタンは48pt、解除画面は52pt。

アプリの名前とアイコンはFamily Controlsの表示を利用する。一般アイコンはSF Symbols。英数字は添付HTMLのInterを同梱し、日本語はiOSのフォントへフォールバックする。文字サイズはDynamic Typeに追従し、アクセシビリティサイズでは曜日と時刻の配置を切り替える。

広告SDKの通信と端末内保存を区別するため、設定の「広告で扱う情報」に既存の説明を残した。テスト広告を使う開発版では、その旨を解除画面に表示する。
