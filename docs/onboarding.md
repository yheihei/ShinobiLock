# カルマの案内

初回起動で4画面の案内を表示する。参照は `/Users/yhei/Downloads/Shinobi Lock3.html` の4a〜4e。

1. カルマの自己紹介。
2. 曜日・時間帯・アプリでロックルールを作る説明。カードは見本で、ルールを保存しない。
3. 本人が一時解除を選んだときの条件。広告を最後まで見ると対象アプリだけ5分間使える。途中終了では解除しない。
4. 「はじめる」でホームに進む。スクリーンタイムの許可は、ホームで本人が選んでから求める。

最初の3画面には「スキップ」を表示する。スキップと最後の「はじめる」のどちらでも、端末内の `UserDefaults` に `onboarding.completed = true` を保存する。案内の途中でアプリを終了した場合は未完了のままなので、次回は最初から表示する。この版への更新後も、完了記録がない端末では一度表示する。

設定の「カルマ」節にある「案内をもう一度見る」で、同じ4画面を全画面表示する。再表示では上部が「閉じる」、最後のボタンも「閉じる」になる。閉じると設定に戻る。再表示は初回完了の記録、ルール、広告の状態を変えない。

## セリフと立ち絵

2026-09-14にNINJAMCPの `get_character` `get_character_image` `search_lore` `get_worldview` でカルマの設定を再確認した。公式設定は風魔所属、鎖鎌、赤い瞳の瞳術で、口調や性格の指定はない。案内のセリフはクールなツンデレとしてアプリ用に創作した。解除・休止・削除の既存セリフと同じく、「……」の間、「おまえ」の呼びかけ、短い文で組む。突き放す言い方のあとに、心配や期待を別の理由にすり替えて言う。吃音や甘えた言い回しは使わない。各行は全角16字以内に収め、通常サイズの402pt幅で折り返さないようにする。

| ページ | セリフ | 立ち絵 |
| --- | --- | --- |
| 1 | ……何だ、おまえか。カルマだ。おまえの時間を見張る。勘違いするな。暇だっただけだ。 | `karma-onboarding-intro`: 腕を組み、顔を背けて横目でこちらを見る |
| 2 | 曜日と時間を決め、アプリを縛る。それが「ルール」だ。簡単だろう。……まずは一つ。倒れたら困る。 | `karma-onboarding-rules`: 人差し指を立てて講釈する |
| 3 | どうしてもと言うなら広告を見ろ。5分だけ、鎖を緩めてやる。その無様な顔は覚えておくがな。 | `karma-onboarding-unlock`: 鎖を両手で張り、上目遣いに睨む |
| 4 | ……話は終わりだ。行け。あとは、おまえが決めればいい。守れたら、褒めてやらなくもない。 | `karma-onboarding-farewell`: 背を向け、肩越しに振り返って小さく手を振る |

3ページ目は本人が解除を選んだときの条件を述べるだけで、利用を勧めない。

立ち絵4点はCodexの内蔵画像生成で作成した。NINJAMCPの公式2D・3D画像と、カルマの間で使用中の `karma-cool-smirk` を参照に渡し、線の太さと頭身を揃えた。緑の単色背景で生成し、`output/onboarding-portraits/process_portraits.py` で透過化して1024pxに統一した。プロンプト、採用画像、確認結果は `output/onboarding-portraits/` に保存している。旧画像の `karma-coach-front` と `karma-onboarding-lookaway` は削除し、設定の「案内をもう一度見る」の絵は `karma-onboarding-intro` に変えた。

小型画面も通常と同じ縦並びを使う。説明ページは200pt、導入と締めは320ptの画像、台詞は21ptを基本とする。本文が高さを超えたらスクロールし、上部の操作と下部の主ボタンは固定する。文字サイズは端末の設定に追従する。

## ファイル

- `App/OnboardingView.swift`: 画面と進行、設定からの再表示。
- `App/ShinobiLockApp.swift`: 初回表示の判定と完了の保存。案内の表示中も既存ルールの同期を継続し、一時解除画面の自動表示は案内を閉じるまで待つ。
- `App/SettingsView.swift`: 再表示への入口。
- `App/Resources/karma-lines.json` の `onboarding`: 表示順に並べた4本の台詞。既存の解除・休止・削除用の台詞とは別に管理する。
- `karma-onboarding-intro` `karma-onboarding-rules` `karma-onboarding-unlock` `karma-onboarding-farewell`: ページごとの立ち絵。既存のカルマの間の画像は置き換えない。

古い台詞ファイルや空の台詞でも、各ページに対応する予備の台詞を使う。
