# Inter

Inter-Regular.ttf and Inter-Medium.ttf were converted from the Latin WOFF2 face
embedded in the supplied Shinobi Lock.html design. The weight axis was fixed at
400 and 500, respectively; the glyph outlines were not edited. Japanese text
uses iOS font fallback.
